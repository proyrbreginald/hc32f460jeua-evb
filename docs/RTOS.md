# RTOS 内核

`src/rtos/` 是单核 Cortex-M4F 上的 RT-Thread v5.2.2 语义移植。内核不依赖
板级驱动和应用模块，通过架构 facade 使用 PRIMASK、WFI、PendSV 等原语。

## 调度模型

- 32 个优先级就绪队列，每级侵入式双向链表；
- `READY_GROUP` 位图快速定位最高优先级就绪线程；
- 同优先级线程按时间片轮转，时间片为 0 表示不参与轮转；
- 运行线程仍留在 READY 队列，调度器只比较最高就绪线程和当前线程；
- 调度请求写入 PendSV 挂起位，真正寄存器保存/恢复在最低优先级 PendSV 中完成。

## 线程生命周期

`thread_create` 分配 TCB 和栈、构造初始异常帧并加入就绪队列。线程入口返回后跳
入 `thread_exit`，先从调度队列摘除并进入 defunct 队列，再由 idle 线程在原线程
不再运行后回收栈和 TCB。`Arc<Thread>` 句柄保证用户观察线程状态期间 TCB 不悬垂。

线程延时通过内嵌定时器进入睡眠队列；tick 到期后唤醒并重新参与调度。所有线程栈
均须固定地址，启动定时器或入链后不得移动对象。

## IPC

| 类型 | 语义 |
|---|---|
| `Semaphore` | 计数信号量，支持有限 tick 或永久等待 |
| `Mutex<T>` | 非递归互斥量，守卫提供受保护数据的 `DerefMut`，支持优先级继承 |
| `Event` | 位标志等待，支持 AND/OR 及接收后清除 |
| `Mailbox<T>` | 固定槽位、类型安全的单值消息，支持紧急插入 |
| `MessageQueue` | 固定消息大小的字节队列，发送/接收均可超时 |

阻塞方挂入对象等待队列并启动线程定时器；超时、释放或事件满足条件都会走统一的
唤醒/重新调度路径。内核对象的消息池在临界区外通过 CAS 一次性发布，关中断区间
不得发生堆分配。

## 临界区与定时器

内核共享状态以 PRIMASK 临界区保护，`CriticalSection` 令牌将借用生命周期限制
在临界区内。定时器按绝对 tick 有序插入，tick 回绕比较必须使用回绕安全差值；
回调在退出内核临界区后于中断上下文执行，因此回调只能调用非阻塞、中断安全 API。

## 上下文与移植边界

`context.rs` 实现 Cortex-M4F PendSV：保存 `r4-r11` 和线程 EXC_RETURN，按需处理
惰性浮点上下文，再恢复目标线程 PSP。换 CPU 时，调度/IPC/线程语义可以复用，必须
重写 `src/arch/` 和上下文切换实现，具体顺序见 [PORTING.md](../PORTING.md)。

## 内核修改规则

- 不在 ISR 或定时器回调中调用可能阻塞、分配或访问 shell 的 API；
- 侵入式链表节点入链前必须固定地址，摘链和状态迁移必须在同一临界区完成；
- 修改唤醒路径时同时检查超时、删除、线程退出和优先级继承四类调用者；
- 使用 `selftest` 和 soak 覆盖 IPC、线程回收、定时器漂移、优先级继承和调度延迟。
